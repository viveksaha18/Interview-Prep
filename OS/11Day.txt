# 1️⃣ Memory Management

## Definition

Memory Management ka matlab hai **RAM ko efficiently manage karna**, taaki CPU easily data aur instructions access kar sake.

```
CPU ↔ RAM
```

Operating System memory allocate, deallocate aur protect karta hai.

# 5️⃣ Memory Capacity

Formula

```
Memory Capacity

=N × m bits
```

Where

```
N

↓

Number of Words
```

```
m

↓

Word Length
```

Example

```
1024 ×16

=16384 bits

=2048 Bytes

=2KB
```

---

# 6️⃣ Address Bus Relation

Suppose

Address Bus

```
p bits
```

Total addresses

```
2^p
```

Hence

```
N=2^p
```

And

```
p=log₂N
```

---

# 7️⃣ Important Conversions

```
2^10=1K

2^20=1M

2^30=1G

2^40=1T

2^50=1P
```

# 8️⃣ Memory Numericals

## Formula

```
N=2^n
```

```
n=log₂N
```

```
Memory=N×Word Size
```

---

## Address Lines

```
Address Lines

=log₂(Number of Words)
```

---

## Data Lines

```
Data Lines

=Word Length
```

---

## Example

Memory

```
4K×16
```

Solution

```
4K=4096=2^12

Address Lines=12
```

```
Word Length=16

Data Lines=16
```

# 🔟 Linking

## Definition

External references ko resolve karna.

Example

```
printf()

scanf()

sqrt()
```

---

Flow

```
Source Code

↓

Compiler

↓

Object File

↓

Linker

↓

Executable

↓

Loader

↓

RAM
```

---

## Static Linking

- Libraries executable ke andar copy hoti hain.

Advantages

- Fast
- Secure

Disadvantages

- Large executable
- Memory waste

---

## Dynamic Linking

Libraries runtime pe load hoti hain.

DLL use hoti hai.

Advantages

- Small executable
- Memory Efficient
- Reusable

Disadvantages

- Slow
- Less Secure

---

## DLL

Dynamic Link Library

---

## Stub

Small piece of code.

Actual function ka address batata hai.

|--------|----------|

---

# 1️⃣2️⃣ Types of Address Binding

## Compile Time Binding

Compiler absolute address generate karta hai.

✔ Fast

❌ Flexible nahi.

---

## Load Time Binding

Loader address assign karta hai.

Relative Address

↓

Absolute Address

---

## Execution Time Binding

Runtime pe address change ho sakta hai.

MMU use hota hai.

✔ Most Flexible

---

# Comparison

| Compile | Load | Execution |
|----------|------|-----------|
| Static | Static | Dynamic |
| Compiler | Loader | MMU |
| No relocation | Loader relocation | Runtime relocation |
